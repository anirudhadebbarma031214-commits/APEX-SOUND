# APEX SOUND

FxSound-inspired Android audio enhancer with black / cyan / purple gaming styling.

## Included
- Native Kotlin Android app
- 10-band equalizer controls and six presets
- Bass boost and Android Virtualizer effects, when supported by the device
- Local audio file selection and playback
- Neon logo asset
- GitHub Actions workflow to build a debug APK

## Important limitations
This starter app processes only audio played inside this app. It does not enhance sound system-wide for other apps. Android effect availability and band counts depend on the device. The source has not yet been verified by a successful Actions build or device test.

## Build APK
Open **Actions → Build APEX SOUND APK** and run the workflow, or push a commit to main. After a successful run, download the **APEX-SOUND-debug-apk** artifact from the workflow run.
